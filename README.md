## 🌟 核心特性与玩法规则

### 1. 四川麻将核心规则
- **三门牌组（108张）**：仅使用万、筒、条三门牌，无风牌与字牌（东南西北中发白），不可吃牌，仅可碰、杠、胡。
- **强制定缺**：开局前每位玩家必须选定一门不要的花色（万/筒/条）。在手牌中尚有缺门花色时，**必须强制优先打出缺门牌**，且未打完缺门牌前绝不可胡牌（防止花猪）。
- **血战到底（一家胡牌继续打）**：一人胡牌后牌局不结束，胡牌者退出战斗，其余未胡玩家继续摸打，直到牌墙摸完或仅剩 1 家未胡。
- **一炮多响**：一张弃牌可同时供多家点炮胡牌。
- **抢杠胡**：别家补杠（巴杠）时，若该牌恰好为你所听之牌，可直接宣告抢杠胡。

### 2. 刮风下雨与呼叫转移（杠牌收益）
- **暗杠（下雨）**：杠牌者向所有当前未胡牌的玩家各收 2 分。
- **直杠/明杠（刮风）**：点杠者向杠牌者支付 2 分。
- **补杠/巴杠（刮风）**：杠牌者向所有当前未胡牌的玩家各收 1 分。
- **呼叫转移**：若玩家杠牌后摸牌打出被其他玩家胡牌（杠上炮），该玩家本次杠牌所收取的所有刮风/下雨收益将**全额转移给胡牌者**。

### 3. 流局终局结算（荒庄查叫与查花猪）
- **查花猪**：摸完牌墙时，手牌中若仍持有定缺花色的牌为“花猪”，花猪必须赔给所有非花猪玩家 **16分满番**，且退还本局所有杠分。
- **查大叫（查叫）**：流局时未听牌（未叫）的玩家，必须赔给所有已听牌（叫牌）玩家其所听牌型的**最大可能番数分值**，并退还所有杠分（退税）。

### 4. 丰富番型系统（加番累进）
| 番型 | 番数 | 分值 | 说明 |
| :--- | :--- | :--- | :--- |
| **平胡** | 1番 | 1分 | 基础胡牌牌型（顺子+刻子+1将） |
| **对对胡 (大对子)** | 2番 | 2分 | 全部由刻子/杠与1对将组成 |
| **清一色** | 4番 | 8分 | 整副手牌全为同一门花色 |
| **七对 (暗七对)** | 4番 | 8分 | 门前清，手牌全部为 7 个对子 |
| **龙七对** | 5番 | 16分 | 七对中含有 4 张相同的牌（带1根） |
| **金钩钓** | 4番 | 8分 | 4 组副露（碰/杠），手牌仅剩 1 张单钓将成胡 |
| **清对** | 6番 | 32分 | 清一色 + 对对胡 |
| **清七对** | 8番 | 128分 | 清一色 + 七对 |
| **清金钩钓** | 8番 | 128分 | 清一色 + 金钩钓 |
| **带根** | +1番/根 | 分值×2 | 手牌+副露中任意 4 张相同的牌算 1 根 |
| **自摸 / 杠上开花 / 杠上炮 / 抢杠胡 / 海底** | 各+1番 | 分值×2 | 额外加番奖励 |

## 🧠 高级 AI 决策引擎 (Master AI Algorithm)

1. **深度向听数精算 (Shanten Calculation)**：
   - 涵盖标准 4 面子 1 将、暗七对、对对胡等多种牌型路径的精确向听数计算。
2. **有效进张精算模型 (Uke-ire Acceptance)**：
   - 结合全场已见牌（弃牌河与副露区）精确计算未现进张张数，最大化上听与胡牌概率。
3. **大番期望收益博弈 (High-Fan EV Model)**：
   - 当单门花色达到 8 张以上时，倾向于冲刺清一色（4番/8分）；起手 4 对以上时保护暗七对。
4. **押拉防守与危险度评估 (Push-Fold Defense)**：
   - 识别高威胁对手（副露 2~3 组同门牌），在未听牌阶段优先打出绝张与现物（Genbutsu），杜绝轻易点炮。
5. **三档 AI 难度切换**：
   - **入门 (Easy)**：偏基础向听打法，适合练习。
   - **普通 (Normal)**：攻守兼备，兼顾进张与大番规划。
   - **高手 (Hard)**：全向听精算、大番期望值博弈与深度防守。
